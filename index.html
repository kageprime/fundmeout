10 — Loading

One smile, still moving

The loader carries the identity while the product works. Light frame opens the moment, dark frame holds the wait. Same blue and amber, same smile, reduced motion respected.

Start frame · Light · Tagline holds the promise
Spinner · Dark · Smile at the center
Loading…
Behavior
Calm, never blocking

Ring rotates 1.4s linear, smile stays still. Spins only while waiting. Honors reduced-motion by pausing. Blue opens, amber resolves — the same two hues as the start frame.
